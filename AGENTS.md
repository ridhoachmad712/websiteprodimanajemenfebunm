# Project Agent Guidance

Use the project-local anti-slop skills in `.agents/skills/` during relevant work on this website, as requested by the project owner.

- Start with `.agents/skills/antislop/SKILL.md` for UI work.
- Load the applicable companion skill: `antislop-ui`, `antislop-copywriting`, `antislop-human`, `antislop-layoutmobile`, or `antislop-code`.
- Keep changes consistent with the existing Laravel, Blade, and Tabler implementation and the site's established design. Do not change the technology stack for anti-slop.
- For backend-only tasks unrelated to these concerns, use the repository's existing conventions.
